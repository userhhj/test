# 평가 결과 조회 데모

## 다운로드 후 실행

1. GitHub에서 `Code` > `Download ZIP`을 선택하고 ZIP 파일을 풉니다.
2. 압축을 푼 폴더 안의 `index.html`을 엽니다.
3. `index.html`, `styles.css`, `bulk.css`, `app.js`는 같은 폴더에 그대로 둡니다. 이미지나 외부 글꼴은 필요하지 않습니다.

정적 데모는 브라우저 저장소에 자료를 보관합니다. 브라우저나 파일 열기 방식에 따라 저장이 제한될 수 있으며, 그런 경우 새로고침하면 변경 내용이 사라질 수 있습니다. 실제 학생 개인정보와 평가 결과를 입력하지 마세요.

`apps-script/` 폴더는 Google Apps Script용 별도 버전이며, 정적 데모 실행에는 필요하지 않습니다.
